# My Profile

## เกี่ยวกับโปรเจกต์
โปรเจกต์นี้เป็นโปรแกรมแสดงข้อมูลประวัติส่วนตัว (Profile) เพื่อแนะนำตัวเอง โดยใช้ภาษา JavaScript และ TypeScript

## วัตถุประสงค์
- เพื่อฝึกเขียนโปรแกรม
- เพื่อเรียนรู้การใช้งาน JavaScript และ TypeScript
- เพื่อฝึกใช้งาน Git และ GitHub
- เพื่อจัดเก็บข้อมูลประวัติส่วนตัว

## ไฟล์ภายในโปรเจกต์
- `profile.ts` ไฟล์โปรแกรมภาษา TypeScript
- `profile.js` ไฟล์โปรแกรมภาษา JavaScript
- `README.md` ไฟล์อธิบายรายละเอียดโปรเจกต์

## เครื่องมือที่ใช้
- Visual Studio Code
- Node.js
- Git
- GitHub

## วิธีใช้งาน
1. ดาวน์โหลดหรือ Clone โปรเจกต์
2. เปิดโฟลเดอร์โปรเจกต์ด้วย Visual Studio Code
3. เปิด Terminal
4. ใช้คำสั่ง `node profile.js` เพื่อเรียกใช้งานไฟล์ JavaScript
